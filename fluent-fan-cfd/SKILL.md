# Fluent 风机 CFD 工作流

将用户给定的风机几何和运行条件变成可追溯、可续算、可检查的 Fluent 结果。区分原生 CFD 数据、未收敛试算、绘图插值、参考图估读和实测数据。

## 能力边界

这是实验性的风机工程流程技能，附带两个只读分析脚本，不是完整的 CAD/网格/Fluent 一键执行器。其整合经验来自单一 Windows/Fluent 2025 R1 环境，尚无多机型、跨版本或实测验证基准。新几何、新平台、瞬态/多相/传热模型需要适配和验证，不能宣称通用性能预测精度。

## 先确定当前任务

- **接续现有算例**：先读项目交接文件、状态、原生文件和实际进程。最新用户指令优先于旧队列；停止、暂停通知、只做暂定曲线等选择要分别记录。
- **新建/修正 CAD 与网格**：读 [CAD、网格和 MRF](references/cad-mesh-mrf.md)。只有需要编辑 SolidWorks 时再使用已安装的 SolidWorks 技能/工具。
- **求解、后台执行、查看进度或停算**：读 [求解与后台运行](references/solver-background.md)。只看进度时读取持久文件，不额外连接忙碌 Fluent。
- **云图、残差、性能曲线、单位转换或参考图比较**：读 [结果与性能曲线](references/results-curves.md)。不要为改图重跑求解器。
- **适配新项目**：读 [项目参数与边界](references/project-profile.md)。项目路径、尺寸、转速和收敛标准来自当前项目，不从别的风机继承。

## 建立计算依据

记录源 CAD 路径/哈希、实际选用的一侧或整机、坐标单位、轴心/方向、转速与旋向、流量是单臂还是总量、空气条件、原始测量端口，以及用户允许的假设。将参数表、铭牌、CAD 实测分别列为来源；冲突时不自行混合重建。

明确当前使用“原 CAD”还是“参数重建”。叶片外缘、叶轮盘、壳体前盖和旋转域直径分别命名。几何缩放、转向猜测和间隙假设必须有记录，不能将型号直径范围当成当前实际直径。

## 进入求解前的工程检查

1. 空气域闭合且连通，叶轮和固定细节均已正确扣除，进出口封面/延长段可识别；检查实体与流体重叠、单位和体积。
2. 旋转区接口采用与轴相容的解析圆柱/平面等回转面。按单元中心圈选后产生的锯齿接口不自动满足 MRF 条件。
3. 量化接口法向参考系速度差、耦合覆盖/非重叠面积和网格正体积/质量。几何偏差定位到具体面区并评估局部影响，不能为通过检查全局放宽公差。
4. 核对**实际写入 Fluent 的设置**：流体区、壁面运动参考系、轴/角速度、空气、湍流模型、入口流量和出口压力。静止壁绝对速度为零，与转子壁相对旋转区速度为零是不同设置。

保存上述依据后再开始数值求解。几何/接口无效的既有结果只保留为诊断，不通过增加迭代或美化曲线改称性能结果。

## 求解与收敛

单工况先建立可检查的解，再按用户意图选择严格收敛扫参或明确标注的短程试算。正式计算使用适合物理问题的离散阶次；残差、质量平衡、压升稳定性同时监控。阈值属于当前研究设置，不是所有 Fluent 模型的通用规定。

对 SST 六方程风机案例，可用 `scripts/evaluate_convergence.py` 对持久检查点复算数值条件。它不验证几何正确性、网格无关性、实测一致性或整套 Native 文件可重开性。非 SST、传热、多相或瞬态任务要增加相应条件，不能只套六项残差。

每个检查点保存匹配 Case/Data、原生迭代号、流量/压力报告和真实残差历史。热启动的新流量记录自己的迭代起点；父工况的历史不能算入新流量的稳定性窗口。

## 后台运行与停止

一个任务只保留一个活动 Fluent 控制器，采用锁和任务状态防止重复启动。状态 JSON 可能过期，结合进程身份和原生日志确认。处理 PID 时核对创建时间，防止复用误判。

根据实际可用内存/提交量选择并行数，避免在求解时同时读入完整 CAD、网格和流场。云图后处理可在原生保存后延迟；后处理失败与数值失败分开记。

用户要求停止/某时刻结束时，撤销后续工况和自动重启意图，提前在可保存边界停算；验证存盘与进程真正退出。新一轮续算不重启已过期的停止守护。修改磁盘上的 Python 代码不代表已运行的进程会加载新代码。

本地后台计算和应用自动跟进是两件事。保持用户的通知/暂停偏好；只有用户要求调度跟进时才使用应用的自动化工具。

## 交付与曲线

原生 Case/Data、真实压力/速度图、残差/质量/压升记录构成可检查结果；PNG 不能替代原生文件。正式交付在求解器空闲或退出后重开匹配文件并复核迭代/报告，图上迭代与 Data 一致。

性能曲线的每一点来自一个**不同流量**的实际工况。只有一个流量时只能给单点；同一流量的压力迭代史不是 Q–Ps 曲线。用户明确要求未收敛版本时可绘制暂定点，但保留每点残差、局部步数和未收敛标志。

使用 `scripts/curve_table.py` 整理真实点和双单位 CSV；`m³/s = m³/h ÷ 3600`，`质量流量 = 密度 × m³/s`。用户需要平滑时可对已算点保形插值，保留真实点，不外推缺失范围。原始 CFD 点表与绘图采样另存。平滑不表示收敛或精度提升。

## 辅助脚本

- `scripts/evaluate_convergence.py`：检查同工况二阶、六残差、质量平衡和最近检查点压升稳定；可选交叉读取已保存 Data 的原生迭代与缩放残差。
- `scripts/curve_table.py`：校验/排序不同流量点，输出 m³/h 与 m³/s、静压差和来源；暂定结果必须显式选择 `provisional` 模式；可选保形插值输出明确标为绘图数据。

运行前查看脚本 `--help`，使用与本机依赖兼容的 Python。技能脚本仅做文件分析，不启动/结束 Fluent、不自动删文件或迁移磁盘数据。
