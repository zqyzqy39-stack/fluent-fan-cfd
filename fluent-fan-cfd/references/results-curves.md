# 真实云图、性能曲线与比较

## 结果身份

每张云图/残差/曲线点保留工况、迭代、Case/Data 路径和状态。区分数值收敛、图已导出、Native 可重开、网格/实测验证；这些不是同一状态。

求解器空闲或退出后原生重开匹配 Case/Data，核对迭代号、入口/出口流量、原端口压力，以及提取场的最小/最大值。需要保证截图来自真实物理量而非几何着色。表面光顺显示不是体网格丢失；显示网格边线或切面体网格前确认当前对象。

解码 HDF5 场与切面时保持 native cell ID、face chunk 顺序、NCI 占位面处理一致。单元中心值与节点插值值分别命名；图中的全域极值不能与不同统计位置的值冒充一致。

## 压力定义

明确差压符号、截面、面积/质量加权方式、静压/全压、表压/绝压和延长管是否排除。对本案例，曲线为原 CAD 出口减入口的面积平均**静压差**。

该端口静压差不自动等于标准风机静压定义。参考图标 Ps/Pt 时先确认原图定义及试验条件；不能只看到“Pa”就称两者可验证。全压差也不能由静压曲线任意加一个常数产生。

## 不同流量才构成性能曲线

每点来自实际改变流量并迭代的独立工况。压力随同一流量迭代的曲线，只能标为迭代历史。

暂定图允许未收敛点，但每点局部步数、六残差、质量不平衡和来源要保留，不把缺失点填零。正式图仅纳入满足当前工程门槛并复核原生匹配文件的点。单点不足以确定曲线形状。

`scripts/curve_table.py --mode provisional` 将真实点标准化并保留未收敛标志。`--mode final` 额外要求输入带数值收敛和 Native 匹配复核标志；它**只验证元数据合同，不亲自运行 Fluent 复核**，调用者需先取得实际证据。

使用示意模式时，与实际数据分文件/标题，不能用铭牌单点或相似风机关系补成“Fluent曲线”。

## 单位和平滑

- `Q[m³/s] = Q[m³/h]/3600`；同一条曲线的纵坐标完全相同。
- 单臂与整机总量必须在表头/图注区分。双臂几何对称不意味着所有真实运行条件下都能直接倍增。
- 可按用户示例采用黑色密网格，但刻度必须按实际流量，不能照搬参考图的0.25m³/s到只算200m³/h的数据。
- 用户要求平滑时优先保形插值（如PCHIP）通过已算点，保留真实点。不得为了看起来像参考图而扭曲数值、强加陡降段或外推未算流量。
- 原始结果表与插值采样分开。辅助脚本可另存 `--smooth-output`，显式标为 display interpolation；它不是更多 CFD 工况。
- 同一页整理 m³/h 和 m³/s 图时使用相同纵轴和对应的物理横轴范围。配套保留双单位数据表、PNG/PDF/SVG。
- Windows 下 PDF/CSV 被用户打开可能不能替换。先导出临时文件，再原子更新；被占用就保留原件、另存版本并记录实际路径，不因绘图错误中断求解。

## 参考图对比

选择相同物理量（例如下方Ps，而非上方Pt），校准有数字标记的坐标。记录源图哈希、像素刻度、线中心估读方式和合理读图误差。截图估读不能冒充厂家原始数据。

统一单位，在相同流量点比较，分别报告绝对差值/相对差异；只比较重叠区。不根据各自铺满画布的曲线形状判断相似。注意 y 轴截断也会改变视觉斜率。

要评估“是否相似”，分开回答：

1. 总体变化方向；
2. 同流量数值偏差；
3. 重叠区下降量/局部斜率；
4. 全流量范围是否覆盖；
5. 几何、转速、密度和压力定义是否可比。

未收敛 CFD 与未知试验条件参考图的差异，不能称为已验证仿真误差，更不能给精度保证。需要先统一条件、取得数值收敛证据，再根据用途做网格无关性和实测核验。
