# 求解与后台运行

## 状态与来源

每个工况独立输出目录。建议持久状态包括：源几何哈希、工况流量/转速、控制器 PID/创建时间、原生进程身份、阶段、活跃日志、该工况迭代起点、最新完整检查点和文件路径。状态文件原子替换；读取时容忍短暂不可读，不把缺失字段当零。

状态可能在崩溃后仍写着 iterating。检查匹配的进程身份、日志实际推进和文件更新时间；不要只看 PID 存在，也不要只看某个写入缓冲尚未刷新的时间戳。控制器/原生进程消失且日志无异常时记录原因未明，不捏造 OOM 或用户终止。

接续一个忙碌算例只读其持久文件和进程。不在同一 Fluent 上建第二个客户端、不为了进度/云图再启动整套原生模型。可用轻量只读进度窗口，每几秒解析日志尾部；迭代完成百分比不是收敛百分比。

## Windows/PyFluent 的本机经验

使用已安装版本和当前可用 API；先查本地签名或官方文档，避免猜工作流字段。CAD cp312 与科学计算 cp314 的编译依赖不能混用。

251 本机实践：

- `-hidden` 与 `-gu` 互斥。两者叠加可能进入读 stdin 的模式并 EOF 退出；隐藏进程保持输入管道以及启动对象生命周期。
- 服务端日志、serverinfo、启动目录保留。serverinfo 含连接口令，不在输出、报告或技能包中展示。
- 自动识别把本机192.168地址当远程时，只有已确认本任务本机会话才显式连接；不更改网络/权限配置。
- 独立隐藏后台工作可以用本机已验证的 WMI 方式；启动成功返回 PID 不代表工作成功，之后必须看到实际状态/原生操作。
- `Start-Process` 受启动环境生命周期影响；需要长时间运行时验证跨命令仍存活。用户要求查看窗口时，确认真正有可见主窗；生成了定时快照不证明窗口可见。
- PowerShell 将 JSON ISO日期自动解析为 DateTime，比较字符串会受小数精度影响。进程身份应比较 UTC 时间值/Ticks，不因匹配失败就称“已停止”。
- WindowsPowerShell 在特定错误偏好下会把 Native stderr 当终止错误，截断 Python traceback。必要时采用简单 Python 包装器直接持久化 stdout/stderr。
- Fluent 原生写文件对中文目录可能有限制；结构化 API 可处理空格，裸 TUI 拼接路径可能截断。先验证本版本，原生输出采用可读 ASCII 目录；中文说明和图片可另存。

这些是本机路线，不代表所有版本都要求相同启动参数或目录。

## 资源与分批

根据实际空闲物理内存与可提交量选择并行数。增加 MPI rank 可能增加内存开销；改变并行数也可能改变缩放残差归一化，不把重启时残差跳变直接当成物理解变化。

将求解拆成可检查批次。在小批次边界更新进度/检查停止条件，在合适检查点保存匹配 Case/Data、原始残差、端口报告。短程试算的步数由当前用户目标决定，不是通用收敛步数。

求解内存紧张时延后切面提取和绘图。标记“数值保存完成、后处理待处理”，不要因为图片失败重新求解或丢弃有效 Data。后处理时释放本任务空闲隐藏原生会话，再读取实际数据；不关闭无关的用户会话。

## 收敛与续算

正式收敛条件应覆盖离散阶次、方程残差、质量/必要的能量平衡，以及关注的压力、扭矩等量的稳定。残差数值不是压力/效率误差百分比。

辅助脚本默认示例阈值：二阶；六项缩放残差全部<1e-4；质量不平衡<0.1%；末3检查点静压差 `(max−min)/max(abs(mean),1Pa)` <0.5%；新工况局部迭代至少400。这些是可调的示例设置，不是所有研究的统一标准。

`scripts/evaluate_convergence.py` 复算上述类别的门槛，可通过选项变更具体阈值。它从历史重算稳定性，不盲信已有 `converged` 布尔值。输入只含单个暂定检查点时应报告稳定性证据不足。

热启动时，新流量继承的是初猜，不是该流量的已算结果。记录 native iteration origin，按本工况局部步数判断；清除父工况历史，或严格过滤。不可用70工况的旧压力窗口给100工况判稳。

重启优先读取匹配 Case&Data，并核对原生迭代。Native HDF5 的 residual `data[-1,0]/data[-1,1]` 在本案例等于实际缩放残差，已与控制台同一迭代行核对；版本/文件结构变更时再次核对。只读取小的残差数组，无需把全场读入内存。

## 正式曲线与暂定曲线

用户以尽快出曲线为先、明确接受未收敛时，可先对多个实际流量短程试算，保存每点残差、质量不平衡、局部步数、初猜来源及匹配文件。独立于正式验证曲线，不能降低正式门槛后改称收敛。

不要让“只等基准完全收敛”的旧队列无限阻挡已授权的多流量暂定方案；也不要在暂定扫参完成后擅自恢复长时间正式求解。

## 停止、存储和交付

计划停止应在截止前选择可保存边界，撤销所有后续/重启动作。优先完成正在进行的原生存盘，不把部分写入文件当完整检查点。若停止导致点未保存，明确最后有效点。

只有已核实属于本任务且身份匹配的进程才能处理。强制结束是停算/恢复的最后手段；保留可恢复文件与真实原因。实际核验无剩余进程后才报告停止成功。

源代码文件修改不更新已加载函数。活动控制器继续用旧绘图函数时，可在存盘后另起只读导出器使用新版绘图代码；不能再建 Fluent 客户端。

用户要求磁盘迁移时：只对明确目录执行，先复制到充足空间的目标盘，核对文件数量、大小与每文件 SHA256，再释放原副本；保留路径映射。Windows 删除/移动前检查最终绝对路径，目录链接不能递归当普通目录处理。实时目录和历史目录分开；不要因为“大文件”就删除唯一 Case/Data。
