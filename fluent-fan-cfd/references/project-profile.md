# 适配新项目

本文件描述需要向当前项目获取的信息，不含真实客户案例。资料可放入仓库外的私有配置目录；不要公开 CAD、许可文件或会话连接信息。

## 最小信息

| 类别 | 需要记录 |
|---|---|
| 几何 | 源文件/哈希、mm或m、叶片与盘片直径、空气域/固体、选取单侧或整机 |
| 运动 | 轴心、轴向、旋向、RPM或rad/s、旋转/静止壁归属 |
| 工况 | 单臂或总量、流量范围、参考密度/黏度、原始测量端口 |
| 物理 | 稳态MRF或瞬态、湍流模型、是否传热/组分/多相 |
| 求解 | 软件版本、Python和API、可用内存/磁盘、并行数、停止方式 |
| 证据 | 几何/接口审核、Case/Data、原生迭代、报告和残差、相应哈希 |
| 交付 | 允许的假设、正式或暂定结果、收敛门槛、通知偏好 |

源文件缺少尺寸时优先测量，不把图表的型号范围直接当作当前叶轮尺寸。用户允许工程假设时，分别记录假设及其影响。

## 包内输入合同

- `evaluate_convergence.py` 接受单工况检查点 JSON 历史，见 `examples/history.synthetic.json`。
- `curve_table.py` 接受不同流量的真实点 JSON；示例 `examples/points.synthetic.json` **完全是合成测试数据**，不是 Fluent 结果。
- 当前收敛脚本固定为 SST 六项残差、稳态二阶和质量/静压稳定性。改变模型时扩展方程与统计条件；不要给能量方程、多相体积分数或瞬态周期平均虚假的通过标志。
- Native Data 交叉读取仅实现一种已观察的 Fluent HDF5 残差布局；没有覆盖全部软件版本。先核对文件结构与原生控制台。
- final 模式只检查输入的收敛/重开标志与来源字段，不自行认证 Case/Data。调用者必须先取得真正的重开证据。

本仓库没有自动读取 CAD、生成体网格或调用 Fluent 的通用执行器。实际运行这些步骤需要用户的合法软件、模型与现场适配脚本。
